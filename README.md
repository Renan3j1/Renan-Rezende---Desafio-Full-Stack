# SOBRE AS STACKS
Para este desafio optei por utilizar no Back-End:
- Python -> FastAPI para criação dos endpoints.
- Postgres -> Banco de dados, apesar de não ser o melhor para este propósito é o que eu mais gosto.
- Keycloack -> Para controlar os tokens de login e cadastro de usuários na plataforma WEB (poderia ter outros escopos como mobile etc).

No Front-End:
  - Node.js -> React + Vite + Javascript -> Estou habituado em utlizar em 90% dos meus projetos (não utilizei tailwind pela simplicidade mas com certeza vale a pena acrescentar)

Gostei do desafio, poderia complementa-lo com alguma integração de LLM ou implementando outros serviços complementares open source além do Keycloack.

Optei pelo keycloack por já ter trabalhado com ele em um momento, uma solução open source e muito completa para resolver todo Auth da plataforma.

Utilizei inteligência artificial para codar parte do front-end, algumas lógicas e o .bat do projeto.

# COMO UTLIZAR? 

1 - Istale o docker desktop.
2 - Baixe o ZIP do projeto e extraia para uma pasta.
3 - Execute o "iniciar.bat".
4 - Ao fim da execução o servidor estará aberto em "http://localhost:5174/".
5 - Crie uma conta e utilize a plataforma.
